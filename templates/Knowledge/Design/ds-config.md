## Implementation mode

| Key | Value |
|---|---|
| Mode | [FILL — `component-library` or `tokens-only`] |

- **`component-library`** — a code package of DS components exists (React / Vue / Web Components…). Skills import components from it and audit for wrong imports.
- **`tokens-only`** — no component package. Skills build with plain HTML/CSS (or the app's framework) using the token variables below, and every reusable piece is composed from tokens. Import checks are skipped.

## Static scan patterns

Used verbatim by the grep checks in `/15-ds-build` Step 4 and `/16-ds-compliance-check` Step 3.

| Check | Pattern |
|---|---|
| Hardcoded colors | `#[0-9a-fA-F]\{3,8\}\|rgb(\|rgba(\|hsl(` |
| Forbidden imports | [FILL — a grep alternation built from *Forbidden imports*, e.g. `@mui/material\|antd`; leave **empty** in tokens-only mode or when `none`] |

| Arbitrary px | `"[0-9]\+px"` |
